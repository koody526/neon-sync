# NEON SYNC — 소스 열람본

HTML·CSS·JavaScript 자판기 웹 실습의 코드 사본입니다. 잔액·재고·품절 상태와 색상 패턴 입력에 따른 구매 조건을 다룹니다. 실제 결제나 서버 인증 기능은 없습니다.

배경과 상품 이미지 9개는 사용자가 AI로 생성했다고 확인했습니다. 이번 코드 공개 후보에는 이미지를 포함하지 않았습니다. 이 사본은 코드 열람용이며 원본 화면을 그대로 재현하는 실행 패키지가 아닙니다. 완성 화면이 필요하면 사용 허가된 이미지로 교체한 별도 사본을 준비합니다.

- index.html: 화면 요소
- style.css: 배치와 상태 스타일
- script.js: 금액·재고·패턴 입력 처리
